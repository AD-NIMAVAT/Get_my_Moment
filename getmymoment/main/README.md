# Get My Moment

**Tagline:** Shoot. Upload. Let Them Find.

AI-powered event photo delivery platform for photographers.

**Customer:** Photographer / studio  
**End user:** Event guest

## Core Flow

Photographer uploads event photos → Guest scans QR → enters details → gives face-search consent → takes/uploads selfie → AI searches only that event → guest receives a private matching gallery.

## Current Goal

Build a zero-cost local prototype first:

- 1 photographer
- 1 event
- ~1,000 photos
- QR access
- Name + mobile
- Selfie capture/upload
- Event-only face matching
- Private gallery

## Vision

1. Local prototype
2. Real photographer pilot
3. Live uploader
4. Cloud SaaS
5. Paid plans
6. Photographer management platform
7. Global expansion
